# Sports Player Analytics

React/Vite website embedding the provided public Power BI report.

## Deploy to Vercel
1. Upload this folder to GitHub.
2. Import the repository into Vercel.
3. Vercel detects Vite automatically.
4. Deploy.

The Power BI report is already configured in `src/main.jsx`.

## Important
The Power BI report uses Publish to web. The report is publicly accessible, so do not use this setup for confidential data.
